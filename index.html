Client Fix Page

Run the diagnostic script on a client, load its report here, and see which script gets the device healthy again for patching, Intune, Entra ID and Defender.

1 Run the diagnostic

Run this on the affected client in an elevated PowerShell. It only reads; it changes nothing.

powershell.exe -ExecutionPolicy Bypass -File .\Get-ClientHealth.ps1 -Anonymize -CopyToClipboard

Download Get-ClientHealth.ps1

2 Load the report

Drop the JSON report here or click to choose a file.

The report is processed in your browser only. Nothing is uploaded or stored.
